## 未修的观察级（后续 issue 候选）

1. **runs 注册表只增不减**；client 构建失败时 run 状态不回写（FE-3 的超时兜底已缓解用户可见面）。
2. run 进行中删除模板可能产生指向已删 template_id 的"僵尸标注"（低概率；vl_annotations 对 templates 无 FK）。
3. 响应体无大小上限（仅 180s 超时兜底；可信网关下可接受）。
4. `model` 无环境变量覆盖（url/key 有），不一致。
5. 多 token 查询含单字 CJK 时（如「过 photo"）该 token 不降级 LIKE——已知行为，文档化即可。
6. json_values 索引 result_json 全部字符串值；raw_text 兜底会把 JSON 键名切进索引。
7. 迁移 v24 回填同步执行无分批（10 万级库启动卡数分钟、失败全量重跑）——大库用户出现前改分批。
8. 写路径每文件 ~12-14 条语句（无 PRAGMA 缓存）；批量路径对未变化文件也重建——扫描吞吐影响估 30-50%（相对缩略图/embedding 主开销占比小）。
9. `vl.system_template_unsupported` locale 键已无引用（保留避免 17 文件噪音）。
